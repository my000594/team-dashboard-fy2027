# ナビゲーション・メンテナンス（nav.js）

> ルート`CLAUDE.md`から分離した開発メモ（2026-11-08）。該当ファイルを変更する前に読み、構造に関わる変更をしたらここを更新すること。
> 文中の「〇〇.htmlセクション」は`docs/dev/pages/〇〇.md`、「△△.js節」は`docs/dev/shared/`、「データフォーマット節」は`data/CLAUDE.md`、「組織設定」節・「技術スタック」節はルート`CLAUDE.md`を指す。


- ページ読み込み時に `data/maintenance.json` をfetch
- `active: true` で全ページがメンテナンス画面に切り替わる
- ロゴ・サブタイトルは「第1ライン / FY2027 Dashboard」
- **モバイル版（900px以下）のナビはアイコン下に短縮ラベルを表示する**（2026-08-23追加。Artifactでモック比較した3案からB案「アイコン＋ミニラベル」を採用）。`NAV_ITEMS`の各項目が持つ`mini`（短縮ラベル、例：インフォメーション→「情報」、3SEレポート→「レポート」、キャリアロードマップ→「キャリア」）を`.nav-label-mini`として出力し、900px以下では`.nav-label`（フルラベル）を隠して`.nav-label-mini`を表示、`.nav-item`を縦並び（アイコン上・ラベル下）にする。デスクトップ表示・レール幅（64px。以前は60pxだったがラベル分の余白を確保するため微増）以外の構造は変更していない。ページを追加する際は`NAV_ITEMS`に`mini`も忘れず設定すること
