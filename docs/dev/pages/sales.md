# sales.html（売上）

> ルート`CLAUDE.md`から分離した開発メモ（2026-11-08）。該当ファイルを変更する前に読み、構造に関わる変更をしたらここを更新すること。
> 文中の「〇〇.htmlセクション」は`docs/dev/pages/〇〇.md`、「△△.js節」は`docs/dev/shared/`、「データフォーマット節」は`data/CLAUDE.md`、「組織設定」節・「技術スタック」節はルート`CLAUDE.md`を指す。

- `data/sales.csv` を縦持ち形式でfetch・集計
- 単位：千円（表示は数字のみ、凡例に「単位：千円」と明記）
- 顧客別にクリックで月別詳細展開（予算・実績・予算差・達成率）
- ヒートマップ：顧客×月の達成率を色で表示
- 実績=0の月は「未確定」として「—」表示
- 予算差（見込・実績）：月が確定（実績>0）していれば「予算差（実績）」、未確定なら「予算差（見込）」を採用し、1つの「予算差」として表示する（両方同時には出さない）。どちらもCSVに値が無い行は「—」のまま何も表示しない
  - 月別詳細テーブル：以前は達成率%と情報が重複する色付きミニバー（達成度列）を表示していたが、これを予算差の実額に置き換えた。見込値には小さく「見込」タグを添えて確定値と区別する
  - 顧客一覧行：累計予算差（確定月は実績差・未確定月は見込差を合算＝着地見込）を達成率%の左にチップ表示。値がある顧客のみ表示（画面幅560px以下では省略）
  - サマリーカード：全顧客の累計予算差（着地見込）を5枚目のカードとして追加。CSVに予算差列が1件も無い場合（Notion未同期時）はカード自体を出さず既存4枚のまま
  - ヒートマップ：未確定月でも見込差があれば「予算＋見込差」から算出した予測達成率を薄い色（opacity .7）＋「見」マークで先出し表示する
- 月列（`月`）のパースは`new Date()`ではなく自前の`parseMonth()`を使うこと。Notion同期後の値は「2027年7月1日」のような日本語表記になり、`new Date()`では`Invalid Date`になって月別グラフ・ヒートマップが無言で空になる（2026-08-01に発覚し修正。index.htmlの売上月別グラフも同じ理由で同時に修正済み）
