> 文中の「〇〇.htmlセクション」は`docs/dev/pages/〇〇.md`、「△△.js節」は`docs/dev/shared/`、「データフォーマット節」は`data/CLAUDE.md`、「組織設定」節・「技術スタック」節はルート`CLAUDE.md`を指す。

- 4ファイルを並行fetch：3se_report.csv / sales.csv / member_master.csv / info.csv（「あなたの状況」ウィジェットは自前でCSVを取得するため含まない。詳細は「あなたの状況」ウィジェット（you-widget.js）節を参照）
- インフォメーションは**左右2列**（`.info-split`。2026-11-06変更。Artifactでモック比較した3案から採用。実データでは期間限定が同時に最大6件＋恒常4件あり、以前の上下積み（期間限定5件＋恒常2件）だと一部が隠れていたため）。画面が狭いと右列が下に回り込む
- 左列「期限のあるお知らせ」：期間内のものを`INFO_TOP_LIMIT`（現在8件）まで、表示順→終了日の順に表示。行頭に期限バッジ（`本日`／`残N日`／`M/D`。残7日以内は赤）を揃え、本文はクリックでその場に展開。9件目以降がある場合は「他N件 → インフォメーションですべて見る」リンクをinfo.htmlへ表示。0件のときは「現在、期限のあるお知らせはありません」と表示。種別の色ドットは、実データがすべて`info`で区別の役に立っていなかったため、index.htmlでは表示しない（info.htmlには残っている）
- 開始日から`NEW_BADGE_DAYS`（現在3日間・開始日を含む）以内の項目には紫の「NEW!」バッジをタイトル前に表示する。定数はindex.html・info.htmlそれぞれのスクリプト内に個別定義（md.jsのような共通ファイルには置いていない）。日数を変える場合は両ページの`NEW_BADGE_DAYS`を両方書き換えること
- 課員数は member_master.csv の在籍者数から取得
- 3SE件数は月別列を直接合算（calcTotal関数）
- 売上は sales.csv の実績>0の行を集計
- **恒常インフォメーション**（2026-08-27追加）：期間指定ができない「ずっと意識してほしいお知らせ」（月次提出リマインド等）を、右列「いつも確認すること」に全件常設表示する（件数上限なし）。本文は長いものが多くその場で開くと右列だけ縦に伸びるため、トップでは展開せず、クリックで`info.html?item=タイトル`（該当項目まで自動スクロール＋展開）へ遷移する（2026-11-06変更。左列の期限ありはその場で展開のまま）。詳細はdata/info.csvのデータフォーマット節を参照。恒常項目が0件の場合は右列自体を出さず、左列が全幅になる（`persistentSection`のinnerHTMLを空にすると`.info-split-side:empty`で消える）。期間限定項目（`activeInfo`）が0件でも恒常項目があれば📢インフォメーションカード自体は表示される
