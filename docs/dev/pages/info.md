# info.html（インフォメーション）

> ルート`CLAUDE.md`から分離した開発メモ（2026-11-08）。該当ファイルを変更する前に読み、構造に関わる変更をしたらここを更新すること。
> 文中の「〇〇.htmlセクション」は`docs/dev/pages/〇〇.md`、「△△.js節」は`docs/dev/shared/`、「データフォーマット節」は`data/CLAUDE.md`、「組織設定」節・「技術スタック」節はルート`CLAUDE.md`を指す。

- `data/info.csv`をfetchし、index.htmlと同じロジックで期間内の全件を表示（件数制限なし）
- 右上の「アーカイブ」ボタンで、終了日を過ぎた項目一覧（新しい順）に切り替え表示（恒常項目はアーカイブ表示中は隠す）。もう一度押すと現在の表示に戻る。`?view=archive`付きで開くと最初からアーカイブを表示する（index.htmlの「過去のお知らせも見る」が使用。`?item=`が同時に指定された場合は`?item=`を優先）
- 本文はMarkdown対応（`md.js`の`md2html()`を使用。index.html・knowledge.htmlと共通。以前は3ページに同じ関数をコピーして持っていたが、md.jsに一本化した）
- 「NEW!」バッジ表示ロジックはindex.htmlと同じ（開始日から`NEW_BADGE_DAYS`日以内。詳細はindex.htmlセクション参照）。アーカイブ表示中の項目には出さない
- ナビゲーションの並びは トップ → インフォメーション → メンバー → ... の順
- **お知らせへの直接リンク（2026-08-27追加）**：展開した本文の中にだけ「🔗 このお知らせへのリンクをコピー」ボタンを表示する（一覧をごちゃつかせないため、折りたたんだ状態には出さない）。クリックすると`info.html?item=タイトル`をクリップボードにコピーし、部下へのお知らせ発信時にLINE WORKS等へそのまま貼れるようにしている。識別子はタイトル文字列のみ（お知らせ自体に一意なIDが無いため。knowledge.htmlの👍投票と同じ制約で、**Notion側でタイトルを変更すると既に送ったリンクが該当項目を見つけられなくなる**——見つからない場合はエラーにはならず、自動展開せず通常のページが開くだけ）
- 上記のリンクを開いた側は、`?item=`パラメータの値と一致するタイトルの項目を（恒常→期間限定→アーカイブの順に）探し、見つかった項目まで自動スクロール＋展開し、一瞬ハイライト（`.info-item-flash`）する。アーカイブ側でしか見つからない場合は自動でアーカイブ表示に切り替える。index.htmlは期間限定を上限件数までしか表示せずアーカイブも持たないため、ディープリンクの受け口（`?item=`の解決）は全件表示のinfo.html側にのみ実装している（index.htmlの「🔗 リンクをコピー」ボタンが生成するURLも常にinfo.htmlを指す）
- **恒常インフォメーション**（2026-08-27追加）：📌ミニリストを、現在表示中リストの直前（`id="persistent"`）に常設し、全件表示する。トップページの右列から遷移してくるため、展開した本文には「← トップに戻る」（index.htmlへのリンク）も表示する（期間限定・アーカイブ項目には出さない）。恒常項目は`活性/アーカイブ`の判定（開始日・終了日での絞り込み）の対象外——恒常項目を役目終了させたい場合はNotion側で「表示期間」を「期間」に変えて終了日を入れる運用にする（詳細はdata/info.csvのデータフォーマット節を参照）
