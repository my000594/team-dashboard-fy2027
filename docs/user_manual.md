# ユーザーマニュアル：社会情報インフラ部 第1ライン ダッシュボード

社会情報インフラ部 第1ライン・第1-1ラインのメンバー向けの使い方ガイドです。

関連ドキュメント：[仕様書](./spec.md)｜[管理マニュアル](./admin_manual.md)

---

## 1. アクセス方法

1. ブラウザで以下のURLを開く
   `https://team-dashboard-fy2027.pages.dev`
2. サインイン画面が表示されたら、**自分の会社メールアドレス**を入力して送信する
3. 入力したアドレス宛にワンタイムコード（6桁の数字）が届くので、画面に入力する
4. 認証が通ると、ダッシュボードが表示される

**補足**
- 一度ログインすれば、約1ヶ月は同じブラウザで再ログイン不要（Cookieが残っている間は自動でスキップされる）
- ブラウザを変えたり、Cookieを削除した場合は再度ワンタイムコード入力が必要
- コードが届かない場合は、迷惑メールフォルダも確認してください
- ログインできない・コードが届かない場合は、課長（米花）まで連絡してください（利用を許可されたメールアドレスの登録が必要な場合があります）

## 2. 各ページの見方

| ページ | こんな時に見る |
|--------|----------------|
| **トップ** | 全体の状況をざっと確認したい時。KPIサマリーと直近のお知らせが並ぶ |
| **インフォメーション** | 過去のお知らせや、期限切れになったお知らせも含めて確認したい時 |
| **メンバー** | 誰がどのラインに所属しているか、役職・等級・写真などを確認したい時。上部のタブでライン別・役職別などに絞り込める |
| **3SEレポート** | 自分やチームのレポート提出状況を確認したい時 |
| **売上・数字** | 予算に対する実績の進捗、顧客別の内訳を確認したい時。顧客名をクリックすると月別の詳細が開く |
| **ナレッジ・FAQ** | 業務で分からないこと・社内ルールを調べたい時。キーワード検索やカテゴリ絞り込みが使える |
| **ライン別会議実施計画** | 今後の会議予定・資料リンクを確認したい時 |
| **スキルマップ** | 自分やメンバーの保有スキル・資格を確認したい時。マトリクス／レーダーチャート／スキル検索の3つの見方がある |

## 3. よくある質問

**Q. サインイン画面でパスワード入力を求められる**
A. 通常はメールアドレス入力とワンタイムコードのみで、パスワードは不要です。パスワード欄が出る場合は想定外の画面なので、課長まで連絡してください。

**Q. 表示されている数字がおかしい・古い気がする**
A. データはNotion側の更新をもとに1日1回自動反映されます（手動で即時反映されることもあります）。反映タイミングのズレの可能性があるため、心当たりがあれば課長に確認してください。

**Q. 「メンテナンス中」の画面が出て使えない**
A. データ更新作業や不具合対応のため、一時的にサイト全体を閉じている状態です。しばらく待ってから再度アクセスしてください。

**Q. 自分の写真やスキル評価が反映されていない**
A. 表示内容はNotion側のデータをもとにしています。心当たりがあれば課長・管理者に確認してください。

このダッシュボードに関する質問・不具合報告は、課長（米花）まで連絡してください。
